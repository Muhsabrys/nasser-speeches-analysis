# تحليل خطاب جمال عبد الناصر السياسي

موقع تفاعلي عربي لتحليل خطب وتصريحات جمال عبد الناصر في الشهور الأولى للثورة، موجه كبنية قراءة لمؤرخ يعمل على كتاب عن خطاب ناصر السياسي.

## المحتوى

- `index.html`: الواجهة التفاعلية
- `app.js`: منطق الفلاتر والرسوم
- `style.css`: التنسيق العربي RTL
- `data.json`: corpus مدمج من ملفات `1.txt` و`2.txt` و`3.txt`
- `1.txt`, `2.txt`, `3.txt`: الملفات المصدرية الأصلية

## التشغيل المحلي

```bash
python3 -m http.server 8765
```

ثم افتح `http://127.0.0.1:8765/`.
